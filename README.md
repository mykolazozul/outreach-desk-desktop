# Outreach Desk для Windows

Окреме вікно-програма для [Outreach Desk](https://outreach-desk-topaz.vercel.app/#/about) — робочого місця для холодних листів і повідомлень клієнтам.

## Завантажити

**[⬇ Завантажити для Windows (останню версію)](https://github.com/mykolazozul/outreach-desk-desktop/releases/latest/download/OutreachDesk-Setup.exe)**

Усі версії — у розділі [Releases](https://github.com/mykolazozul/outreach-desk-desktop/releases).

## Встановлення

1. Запустіть `OutreachDesk-Setup.exe` — програма встановиться для вашого користувача (права адміністратора не потрібні) і з'явиться на робочому столі та в меню «Пуск».
2. Якщо Windows покаже «Windows захистив ваш ПК» — натисніть **«Докладніше» → «Усе одно запустити»**. Так Windows реагує на нові програми без платного цифрового підпису.
3. Увійдіть своїм логіном і паролем Outreach Desk.

Видалити: «Параметри → Програми → Outreach Desk → Видалити».

## Що дає програма для комп'ютера

- власне вікно й іконка на панелі завдань — без вкладок браузера;
- значок у треї та сповіщення;
- якщо закрити вікно під час email-розсилки, вона продовжиться у треї.

Сама програма — лише вікно: інтерфейс завантажується з сайту й оновлюється сам, тож нові можливості з'являються без перевстановлення.

Вимоги: Windows 10 або 11 (64-біт).

# Outreach Desk for Windows

A desktop window app for [Outreach Desk](https://outreach-desk-topaz.vercel.app/#/about) — a workspace for cold emails and messages to clients.

**[⬇ Download for Windows (latest)](https://github.com/mykolazozul/outreach-desk-desktop/releases/latest/download/OutreachDesk-Setup.exe)**

Run `OutreachDesk-Setup.exe` — it installs for your user (no admin rights) and adds Desktop and Start menu shortcuts. If Windows shows “Windows protected your PC”, click **More info → Run anyway** (new apps without a paid code-signing certificate get this warning). Sign in with your Outreach Desk login.

The app is just a window: the interface loads from the website and updates itself. Requires Windows 10 or 11 (64-bit).
